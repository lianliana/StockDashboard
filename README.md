# StockDashboard

个人使用的 macOS 股市面板，支持美股、纳斯达克综合、纳斯达克 100、沪深京 A 股，以及上海黄金交易所 Au99.99 现货黄金。左侧管理自选，右侧查看报价、分时与历史走势。股票行情来自腾讯公开行情接口，上海金报价来自新浪财经，黄金走势来自上海黄金交易所官网。界面显示来源提供的报价时间。部分标的可能有延迟，部分北交所标的只提供报价和分时。

## 本地运行

需要 macOS 14 或更新版本，以及 Swift 5.10 或更新版本（Xcode 或 Command Line Tools）。

```sh
bash scripts/build-local.sh
open build/StockDashboard.app
```

在左侧搜索名称或代码，点选结果即可添加。拖动列表行可调整顺序。上移、下移和移除也可从右键菜单或自选栏顶部的「…」菜单操作。

## 上海黄金交易所

搜索「黄金」「上海金」「上金所」「Au99.99」或「AU9999」，添加上海金到自选。价格单位为元/克，涨跌按来源提供的昨收计算，支持分时和 1 周、1 月、3 月、1 年走势。分时包含夜盘，日期根据上金所公布的更新时间与交易日记录确定。

App 打开时每 60 秒取一次最新报价，也可以点击自选列表底部的刷新按钮。休市时显示最近成交价和实际报价时间，公开行情可能存在延迟。股票与黄金分别请求，某个来源失败时保留对应标的的已有报价，其余来源继续更新。

## 通知中心小组件

首次打开 App 后，点 Mac 菜单栏右上角的日期和时间，进入通知中心，滚动到底部点「编辑小组件」，搜索 **StockDashboard**，添加「自选行情」。也可以从桌面右键菜单添加。小、中、大三种尺寸分别展示自选列表最前面的 3、4、10 项。

添加、移除或排序会保存自选并请求 macOS 刷新小组件。主 App 退出后，小组件仍可在系统调度时取行情。网络暂不可用时，卡片显示最近一次可用的报价和对应时间。

上海金与股票共用自选顺序和缓存，小组件同时显示元/克价格。小组件请求每 15 分钟更新一次，实际刷新时机由 macOS 决定。
